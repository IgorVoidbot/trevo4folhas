# Fontes de frontend — instruções locais

Este diretório segue o [AGENTS.md raiz](../../AGENTS.md) e o [perfil Frontend](../../docs/agents/frontend.md). Leia também [Segurança](../../docs/agents/security.md) se alterar recursos, scripts ou política de carregamento.

- Mantenha fontes Tailwind aqui e gere `src/main/resources/static/css/app.css` pelo build.
- Use classes completas, design slate/emerald e aspas simples quando possível.
- Não adicionar CDN, framework JS ou dependência de runtime sem requisito.
- Build de assets deve ser reproduzível com o lockfile e integrado ao empacotamento Java.
